## What this repository is for

This repository is where a new Lite Wallet owner starts. It covers the download, the install
on each desktop system, the signature check that proves the file is the one the project
published, the update and uninstall paths, and the questions people ask before they trust a
wallet with coins. It also carries the pages that explain what the product is, how it compares
with other Litecoin wallets, and how to recognise the real app from a clone wearing its name.

The guides here are written for the moment before the first send: a downloaded installer that
raised a warning, a phone that needs the same wallet, an old forum answer that names a wallet
that no longer exists under that name. Setup questions have a property the other clusters do
not: they are answered once and rarely revisited, which is why this repository also holds the
overview pages a reader needs to decide whether to install at all.

## Who it is for

- **Someone installing for the first time**, who wants the file for their system and a check that it is genuine.
- **A reader deciding between wallets**, who needs a plain comparison rather than a feature table with no context.
- **Anyone who has been told the app is a scam**, and wants to verify the download, the licence and the publisher.
- **An existing owner moving to a new machine or a phone**, who needs the install path and the paper key rule in one place.

## How to use these guides

1. Read the overview first if you have not used the wallet: it explains custody in two minutes.
2. Install from the signed installer for your system, then verify it before the first launch.
3. Write the paper key down before you receive anything, and store it away from the machine.
4. Come back to the update and uninstall guides when a release changes, not before.
5. Use the comparison guide only when you are choosing between wallets, never as a shopping list.

## Common first questions

### Do I have to install before I can receive Litecoin?

Yes. The wallet generates the keys that own the address, so the address exists once the wallet does. There is no web account that can hold a balance for you.

### Is the desktop app different from the phone app?

The same release ships on every platform, with the same paper key and the same MWEB support. What differs is the packaging and the controls a desktop can show.

### Which download should I pick?

The installer named for your system, from the release table above. Each filename carries the version, so an older file is visibly older.

## Before you install

You need a desktop or phone the wallet supports, a connection for the first sync, and a pen.
The pen is not a joke: the paper key is shown once, and a screenshot on the same machine that
runs the wallet is a weaker copy than twelve words on paper in a drawer. Nothing else is
required - no account, no email, no identity check.
